Accessibility

Accessibility.

We want everyone to be able to use this website. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What we have done

  • Text and buttons meet colour contrast targets.
  • Every page can be used with a keyboard, with a skip link and visible focus.
  • Moving video and logo strips can be paused, and motion stops when your device asks for reduced motion.
  • Every project on the map is also in a plain list below it.

Known limits

The interactive 60-year map is a 3D graphic. Use the project list under the map, which holds the same projects. Some older project images are scans of drawings with small text.

Tell us

If something on the site does not work for you, write to info@pudconsultants.com and we will help and fix it.
